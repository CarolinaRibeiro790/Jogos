## 🚀 Sobre o Projeto
Este projeto foi desenvolvido durante as aulas na faculdade com o objetivo de aprender e praticar os conceitos de desenvolvimento backend utilizando Node.js. Trata-se de uma aplicação simples para cadastro de jogos, onde é possível gerenciar dados através de um sistema conectado a um banco de dados.

## 🛠️ Tecnologias Utilizadas
<li>Node.js: Para criação do servidor backend.
<li>Express: Framework para gerenciar rotas e requisições HTTP.
<li>MySQL: Banco de dados relacional para armazenar informações dos jogos.
<li>EJS: Template engine para renderização dinâmica no frontend.

## 📝 Funcionalidades Principais
<li>Cadastro de jogos com informações como nome e ano de lançamento.
<li>Listagem dos jogos cadastrados.
<li>Edição e exclusão de registros.

## 📚 Aprendizados
Durante o desenvolvimento deste projeto, foram praticados os seguintes conceitos:
<li>Configuração de um servidor Node.js com Express.
<li>Integração com um banco de dados MySQL.
<li>Renderização de templates dinâmicos usando EJS.
<li>Criação de rotas para operações CRUD (Create, Read, Update, Delete).

## 📦 Como Rodar o Projeto:   
npm i (instala as dependências) <br>
npm run dev (inicia o servidor do projeto) <br>
1.  Antes é preciso criar um banco com o nome jogos <br>
2. A minha porta do banco está configurada na 3307, se estiver em outra porta o seu banco alterar no arquivo database.js, dentro da pasta database.
